# E-book «Банк педагогических ситуаций» — прототип

Кликабельный двуязычный (қазақша / русский) прототип по макету UI.
Открыть: двойной щелчок по `index.html` — работает в браузере без сервера и интернета.

## Что есть

| Экран | Маршрут | Что демонстрирует |
|---|---|---|
| Главная | `#/home` | поиск, категории, статистика, шаги работы с кейсом |
| Каталог | `#/catalog` | фильтр по категории и сложности, полнотекстовый поиск (на обоих языках) |

| AI-ассистент | `#/ai/PS-018` | сократический диалог без «правильного ответа», маскировка ИИН/телефона/e-mail, метка AI, кнопка «Сообщить о некорректном ответе» |
| Видео | `#/video/PS-018` | плеер-заглушка + вопросы для анализа |

### Авторизация (демо)

Гость видит каталог, описания кейсов, видео и методматериалы. Анализ, решения, AI-диалог и портфолио — после входа.
В демо вход имитируется: после выбора «SSO» или «LMS» выбирается роль, для сотрудников запрашивается любой 6-значный код (2FA),
при первом входе — согласие на обработку персональных данных. Данные каждого пользователя хранятся отдельно; в профиле — сведения о сессии,
псевдоним, под которым пользователя видит AI, смена роли (демо), отзыв согласия и выход. Права ролей — объект `PERMS` в `src/auth.js`.

Переключатель **ҚАЗ / РУС** в шапке, выбор запоминается. Заметки, решения и рефлексия сохраняются в браузере (localStorage).

## Структура

```
src/i18n.js   — строки интерфейса {ru, kz}
src/data.js   — категории, принципы, 5 демо-кейсов по единой схеме
src/auth.js   — роли, права, экраны входа, кабинеты методиста, эксперта, администратора
src/app.js    — роутер, экраны, демо AI-тьютор
src/style.css — стили (адаптив: ПК / планшет / смартфон с нижним меню)
assets/logo.png — логотип университета (встраивается в index.html при сборке)
build.py      — собирает всё в index.html:  python build.py
```

## Схема кейса (для методистов)

`id, cats[], grade, level, title{ru,kz}, text{ru,kz}, options[{ru,kz,oc,cons{ru,kz}}], expert{ru,kz}, principles[], ai[{ru,kz}]`

`ai[]` — «экспертная карта» для AI: наводящие вопросы, которые тьютор задаёт по шагам.

## Что заменить при переходе к продакшену

- `askTutor()` в `app.js` → запрос к серверу `POST /api/tutor` (LLM + поиск по методбазе, системная инструкция «тьютор», экспертная карта кейса, фильтр персональных данных на сервере).
- `data.js` → API системы управления контентом (Directus / Strapi).
- Демо-вход (`src/auth.js`) → Keycloak (OpenID Connect + PKCE) с федерацией AD университета и LTI 1.3 из LMS; роли и группы — из Platonus; сессия в httpOnly-cookie на сервере.
- localStorage → БД PostgreSQL; журнал действий и жалобы на AI — на сервере.
- Заглушки видео → HLS-плеер с субтитрами kz/ru.
