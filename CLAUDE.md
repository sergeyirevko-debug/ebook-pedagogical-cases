## 3. Прототип (папка EBook)

Одностраничное приложение на чистом JavaScript без сервера, маршрутизация по hash. `index.html` собирается из `src/` скриптом `build.py`, логотип встраивается в виде data-URI.

```
index.html        — собранный прототип (открывать двойным щелчком)
build.py          — сборка: LOGO + i18n.js + data.js + auth.js + app.js + style.css → index.html
src/i18n.js       — строки интерфейса UI.ru / UI.kz
src/data.js       — CATEGORIES, LEVELS, OUTCOME, PRINCIPLES, DIAG_FIELDS, CASES (5 кейсов), ALGORITHM
src/auth.js       — ROLES, DEMO_USERS, PERMS, экраны входа, кабинеты редактора / эксперта / администратора, журнал (audit)
src/app.js        — store/uget/uset, иконки P, роутер render(), страницы, демо AI-тьютор askTutor()
src/style.css     — стили, адаптивность; мобильное нижнее меню при ширине < 860 px
assets/logo.png   — логотип ВКУ (89×112, фон прозрачный; лучше бы версию крупнее)
README.md         — описание для людей
docs/             — Переписка_с_Claude.md, Демо-доступы_e-book.xlsx
```

**Соглашения в коде:**

- Любой текст хранится как `{ru, kz}` и выводится через `t()`; строки интерфейса берутся через `u('key')`. Новые строки добавлять в оба языка. Казахский текст нужно вычитать носителю языка.
- Схема кейса: `id, cats[], grade, level, hue, title, short, text, options[{ru,kz,oc,cons}], expert, principles[], ai[]`.
  - `oc` принимает значения `good`, `risky`, `weak`.
  - `ai[]` — «экспертная карта» с наводящими вопросами тьютора.
- Данные пользователя в localStorage лежат с префиксом `ebook.<userId>.` (через `uget`/`uset`). Общие ключи без пользователя: `user`, `lang`, `consent.<id>`, `audit`, `reports`.
- Кейсы: PS-018 «Смартфон на уроке», PS-027 «Конфликт в классе», PS-041 «Отказ выполнять задание», PS-057 «Работа с родителями», PS-083 «Инклюзия». Имена в кейсах изменены.
- Цифры на главной («200+ кейсов», «50+ видео») взяты из макета и не совпадают с концепцией (≥45 видеокейсов).

**Маршруты:** `#/home`, `#/catalog`, `#/case/<id>/<desc|analysis|solutions|comment>`, `#/ai/<id>`, `#/video/<id>`, `#/materials`, `#/profile`, `#/teacher`, `#/editor`, `#/review`, `#/admin`, `#/about`, `#/login`.

## 4. Принятые решения

- **Форма продукта:** веб-приложение (PWA). Стек для рабочей версии:
  - интерфейс — React или Next.js;
  - сервер — FastAPI или Node и PostgreSQL;
  - контент — Directus или Strapi;
  - видео — HLS с субтитрами kz/ru;
  - аналитика — xAPI.
- **AI-тьютор:** сократический, не выдаёт готового ответа. Опирается на экспертную карту кейса и поиск по методбазе (RAG). Персональные данные фильтруются до отправки в модель; модель видит только псевдоним пользователя. Ответы помечаются как AI, есть кнопка «Сообщить о некорректном ответе», жалобы идут эксперту.
- **Авторизация (финальная версия от 13.10.2026): только собственные учётные записи e-book.** Единый вход университета, Platonus, LMS и eUniver не используются.
  - Студентов заводит преподаватель импортом списка группы (Excel/CSV). Активация — одноразовым кодом из письма или выданным на занятии; код действует 7 дней. Затем пользователь задаёт свой пароль: ≥10 символов, буквы и цифры.
  - Сотрудников создаёт администратор; наставника приглашает преподаватель с ограничением срока.
  - Вход по e-mail и паролю, пароли хранятся в виде хеша Argon2id. После 5 неудачных попыток вход блокируется на 15 минут.
  - Для сотрудников (преподаватель, методист, эксперт, администратор) обязателен второй фактор TOTP.
  - Сброс пароля — ссылкой на e-mail (действует 30 минут) или новым кодом от преподавателя.
  - Сессия — в защищённой httpOnly-cookie, завершается после 8 ч бездействия.
  - При первом входе пользователь даёт согласие на обработку персональных данных (версия 1.0 · 2026-10).
  - **ИИН не хранить.**
  - Реализация — Keycloak в автономном режиме на сервере поз. 16. От университета нужен только доступ к SMTP.
- **Роли и права** (`PERMS`):
  - гость — каталог и описания;
  - студент — кейсы, AI, портфолио;
  - преподаватель — только свои группы, коды активации;
  - методист — редактор, ответов студентов не видит;
  - эксперт — проверка кейсов и жалобы (видит псевдоним вместо ФИО);
  - администратор — пользователи и журнал, без доступа к ответам;
  - наставник — как студент, со сроком.
- **Демо-доступы:** `<role>@ebook.demo` с любым паролем; для сотрудников 2FA — любые 6 цифр; коды активации `STUD-2026` и `MENT-2026`.
